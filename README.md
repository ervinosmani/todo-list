# 📝 To-Do List App (PHP & MySQL)

A simple and clean To-Do List web application built with **pure PHP**, **MySQL**, and **Bootstrap 5**.  
This project includes full CRUD functionality, search, filtering, and input validation. Ideal for beginner to intermediate fullstack developers.

---

## ⚙️ Technologies Used

- PHP (vanilla, procedural)
- MySQL (with PDO)
- Bootstrap 5.3
- HTML5 + CSS3

---

## ✅ Features

- Add new tasks
- Mark tasks as **done / undo**
- Edit task titles
- Delete tasks individually
- **Search** tasks by title
- **Filter** tasks: All / Done / Pending
- **Clear all completed** tasks with one click
- Input validation (empty or too long)
- Responsive UI with Bootstrap
